# Security Policy

## Supported Versions

The following table lists which versions of SantientPHP are currently receiving security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in SantientPHP, please follow responsible disclosure guidelines:

1. **Do not** report security vulnerabilities via public GitHub issues.
2. Email the core maintainers directly or use GitHub's private vulnerability reporting feature if enabled.
3. Include detailed reproduction steps, example `.sph` source code, target platform, and compiler build flags.
4. We acknowledge reports within 48 hours and work with you to coordinate a security advisory and fix.
